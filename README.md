### 🎓 Academia Valhalla — _Proyecto Fin de Ciclo_
Plataforma de aprendizaje de programación con **editor de código integrado (Monaco)**,
**contenido interactivo 3D (Three.js)**, **comunicación en tiempo real (Socket.io)** y
**funcionalidades de IA (Groq SDK)**. Incluye autenticación local y **OAuth con Google y GitHub**,
envío de correos, validación robusta y una API REST documentada.

- **Frontend:** React 19, Vite, TypeScript, TailwindCSS, GSAP, React Router, React Hook Form.
- **Backend:** Node.js, Express 5, Sequelize + PostgreSQL, Passport (OAuth), JWT, Nodemailer, Socket.io.
- **Infra:** Docker Compose para la base de datos en local.

📄 Más detalles en [`PlataAlejandro_PFC/README.md`](./PlataAlejandro_PFC/README.md)

### ⚽ PlayFutBet — _App de predicciones de fútbol_
Aplicación móvil multiplataforma para **predicciones/apuestas de fútbol**, con simulación de
partidos, gestión de plantillas y API propia documentada con **Swagger**.

- **Frontend:** Ionic + Angular 20, Capacitor (Android/iOS), TypeScript.
- **Backend:** Node.js, Express 5, PostgreSQL, JWT, bcrypt, Zod, Swagger.
- 🌐 [Demo desplegada](https://playfutbet-r.vercel.app/login)

📄 Más detalles en [`PlayFutBet/README.md`](./PlayFutBet/README.md)

### 🎬 CineXplora — _App Android nativa_
Aplicación Android nativa para explorar y descubrir cine, desarrollada con el stack oficial de
Android (Kotlin/Java + Gradle), con interfaz adaptada a orientación vertical y horizontal.

- **Stack:** Kotlin/Java, Android SDK, Gradle (Kotlin DSL), recursos XML.

📄 Más detalles en [`CineXplora/README.md`](./CineXplora/README.md)
